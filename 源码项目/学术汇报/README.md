# 空间转录组学入门：详细学术汇报

共 134 页，采用已确认的经典蓝色中文 Madrid Beamer 样式，16:9。
按原讲义 17 章顺序组织为四部分，适合分段录制较长视频。

## 文件

- [直接放映的 PDF](../../讲义与ppt/学术汇报/空间转录组学_CS_AI_学术汇报.pdf)。
- `main.tex`：主源码，依赖同目录的 `theme.tex` 与 `slides.tex`。
- [逐页讲述提示](../../讲义与ppt/学术汇报/逐页讲述提示.md)：与 PDF 页码同步的讲解要点和转场提示。
- [章节页码对照](../../讲义与ppt/学术汇报/章节页码对照.md)：17 章与汇报页码的对照。
- `slides.json`：每页标题、正文、讲述提示和来源说明的结构化副本。
- `images/`：随项目打包的原始教学图片与结构化来源清单。
- `图片来源与许可.md`：各图片的作者、原始链接、许可与使用方式。

## 编译与编辑

请将项目文件保留在同一目录，使用 XeLaTeX 编译 `main.tex` 两次。
Overleaf 中上传完整项目并选择 XeLaTeX；也可使用 Tectonic。
中文使用 TeX 自带的 Fandol 字体。修改标题、汇报人与日期在 `main.tex`；
修改页面内容在 `slides.tex`，修改整体样式在 `theme.tex`。
源码中的 `\note{...}` 已保存逐页提示，默认设置为隐藏，不占放映页面。
