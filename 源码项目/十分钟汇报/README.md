# 空间转录组学：十分钟 Beamer 汇报

依据用户修改后的《空间转录组学_CS_AI入门_讲义.tex》总结。
正文共 11 页（含封面），建议 10 分钟，另有 1 页参考附录。

## 文件

- `main.tex`：Beamer 主文件，16:9，中文，默认隐藏演讲备注。
- `figures/`：从原讲义复用的两幅原始配图，请与主文件一起保存。
- `逐页讲述提示.md`：逐页讲稿和建议用时，正文合计 600 秒。
- `原讲义图片来源与许可.md`：原讲义完整图片清单，本项目仅使用 nucleus.jpg 和 spatial.png。具体出处也已标在相应幻灯片。

## 编译

选择 XeLaTeX，连续编译两次：

```sh
xelatex main.tex
xelatex main.tex
```

也可把完整项目压缩包上传 Overleaf，主文件选择 `main.tex`，编译器选择 XeLaTeX。
中文使用 TeX 自带的 Fandol 字体，无需额外提供字体或 .bib 文件。

作者沿用原讲义的 Auutuumn，可在 `main.tex` 的 `\author{...}` 修改。
报告日期默认留空，可通过 `\date{...}` 填写。
源码中的 `\note{...}` 保存逐页讲述提示。默认 `hide notes` 不在放映版显示；需要带讲稿的版本时，可改为 `show notes` 后另存编译。

封面及学习背景，RNA 表达基础，测量方法比较，真实空间图，表达矩阵与坐标，常见分析流程，AI 任务，肿瘤案例，验证与总结。
