# Beamer 学术汇报模板

这是一个 16:9 中文学术汇报模板，共 9 页。它独立于原讲义，未转换或修改原讲义内容。

## 查看与编辑

- `main.tex`：完整可编辑源码。
- `main.pdf`：编译后的放映版（编译完成后生成）。
- 编译引擎：XeLaTeX，建议连续运行两次。

```sh
xelatex main.tex
xelatex main.tex
```

也可使用 Tectonic：`tectonic main.tex`。在 Overleaf 中可上传该源码并选择 XeLaTeX。

## 模板包含

1. 中英文副标题封面
2. 报告结构
3. 双栏背景与变量定义
4. 数学公式与符号说明
5. PGFPlots 结果图
6. booktabs 三线表
7. 结论与讨论
8. 参考文献占位格式
9. 结束页

## 常用修改位置

- 报告信息：搜索 `报告信息`，修改标题、汇报人、单位、日期。
- 整体配色：修改 `Navy`、`Teal`、`Ink` 等颜色定义。
- 中文字体：默认使用 TeX 发行版自带的 Fandol 字体，无需指定 Windows 字体。
- 图表：修改 `coordinates` 中的数据坐标，图表仍保留为 LaTeX 原生内容。
- 幻灯片：每个 `frame` 环境对应一页。
- 文献：当前为明确标注的占位条目，正式汇报时替换为真实文献。

图表数据均为合成示例，公式是教学设定，不构成真实研究结果。

Beamer 的常用交付形式是 `.tex` 源码和 `.pdf` 放映文件；此项目不包含 PowerPoint `.pptx` 文件。
