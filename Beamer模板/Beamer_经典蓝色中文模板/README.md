# 经典蓝色中文 Beamer 模板

采用 Beamer Madrid 主题，参照用户提供的截图设置主色 RGB(51,51,178)，保留圆角阴影标题框、蓝色通栏页标题、圆球编号与三段深浅蓝页脚。

## 文件

- `main.tex`：可编辑 LaTeX 源码，所有标题和说明均为中文。
- `main.pdf`：16:9 放映文件，共 9 页。
- `模板预览.png`：封面、目录、公式页与结果图的缩略预览。

## 编译

在完整 TeX Live 或 Overleaf 中选择 XeLaTeX，连续编译两次：

```sh
xelatex main.tex
xelatex main.tex
```

也支持 `tectonic main.tex`。中文默认使用 TeX 自带的 Fandol 字体。

## 修改

在源码“报告信息”处填写标题、姓名、单位与日期。五个章节与“汇报提纲”页的五个条目对应，调整章节时同步修改提纲。

图表数据是明确标注的合成数据，公式为教学示例。本项目仅演示模板，未将原讲义转换为正式汇报。
