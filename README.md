## 编辑和编译

进入对应源码项目目录，使用 XeLaTeX 编译两次。TeX 与图片的相对位置已保留，移动或分享源码时应包含整个项目目录。

重新编译生成的 PDF 会留在源码目录。检查后，将讲义 PDF 更新到成品目录；汇报生成的 main.pdf 则以“空间转录组学_CS_AI_学术汇报.pdf”更新到成品目录。成品目录用于保存确认后的版本。

汇报目前是 Beamer PDF，没有 PPT/PPTX 文件。项目压缩包是既有交付备份；修改源码后如需分享最新版，应重新打包。
